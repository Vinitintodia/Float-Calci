## PROJECT OVERVIEW
--------------------------------------------------------------------------------

calculators (Basic, Scientific, and Financial) with keyboard support and a responsive landing page.

Repository: https://github.com/Vinitintodia/voice-calc-vision

## SYSTEM FLOW & ARCHITECTURE
================================================================================

### APPLICATION ENTRY POINT
--------------------------------------------------------------------------------
1. index.html loads the application
2. main.tsx creates React root and renders <App />
3. App.tsx sets up:
   - QueryClientProvider (React Query)
   - TooltipProvider (UI tooltips)
   - Toaster components (notifications)
   - BrowserRouter (routing)
   - Routes configuration


### ROUTING FLOW
--------------------------------------------------------------------------------
Route: "/"
  └─> Index.tsx (Main landing page)
      ├─> NavBar (with calculator toggle buttons)
      ├─> Hero (introduction section)
      ├─> Features (feature highlights)
      ├─> AppDemo (app demonstration)
      ├─> DownloadSection (download CTA)
      ├─> Footer (footer links)
      └─> CalculatorManager (conditional rendering)
          ├─> FloatingCalculator (type: 'basic')
          ├─> ScientificCalculator (type: 'scientific')
          └─> FinancialCalculator (type: 'financial')

Route: "*"
  └─> NotFound.tsx (404 error page)


### CALCULATOR SYSTEM FLOW
--------------------------------------------------------------------------------

1. USER INTERACTION (NavBar)
   └─> User clicks calculator button (Basic/Scientific/Financial)
       └─> toggleCalculator(type) called in Index.tsx
           └─> Updates state:
               - showCalculator: true
               - calculatorType: 'basic' | 'scientific' | 'financial'

2. CALCULATOR RENDERING
   └─> CalculatorManager receives props:
       - type: calculator type
       - input: current expression
       - onInputChange: callback for updates
       - onKeyboardInput: keyboard handler
   └─> Renders appropriate calculator component

3. CALCULATOR FEATURES
   ├─> Draggable (click & drag title bar)
   ├─> Boundary constraints (stays within viewport)
   ├─> Minimize/Maximize (collapse to title bar)
   ├─> Close button (dispatches custom event)
   ├─> Keyboard support (numbers, operators, functions)
   ├─> Voice input (Web Speech API)
   └─> Real-time calculations


### CALCULATOR TYPES & CAPABILITIES
================================================================================

### 1. FLOATING CALCULATOR (Basic)
--------------------------------------------------------------------------------
FEATURES:
  - Basic arithmetic operations (+, -, *, /, %)
  - Decimal point support
  - Plus/minus toggle (±)
  - Clear function
  - Keyboard support (0-9, operators, Enter, Escape)

KEYBOARD SHORTCUTS:
  - 0-9: Number input
  - +, -, *, /, %: Operators
  - Enter: Calculate result
  - Escape/Backspace: Clear


### 2. SCIENTIFIC CALCULATOR
--------------------------------------------------------------------------------
FEATURES:
  - All basic calculator features
  - Trigonometric functions (sin, cos, tan)
    * Automatic degree-to-radian conversion
    * Example: sin(30) = 0.5
  - Logarithmic functions (log, ln)
  - Square root (√)
  - Power operations (^, x², x³)
  - Mathematical constants (π, e)
  - Parentheses support
  - Scientific notation handling

KEYBOARD SHORTCUTS:
  - s: sin()
  - c: cos()
  - t: tan()
  - l: log()
  - r: √ (square root)
  - p: π (pi)
  - ^: Power operator
  - (, ): Parentheses
  - Spacebar: Close bracket )
  - Enter: Calculate
  - Escape: Clear
  - Backspace: Delete last character

CALCULATION ENGINE:
  - Degree-to-radian conversion: degrees * (Math.PI / 180)
  - Function replacement: sin() → Math.sin()
  - Safe evaluation using Function constructor
  - Error handling for invalid expressions


### 3. FINANCIAL CALCULATOR
--------------------------------------------------------------------------------
FEATURES:
  - Compound interest calculations
  - Three input fields:
    * Principal (PV) - Initial amount
    * Rate (i%) - Interest rate
    * Time (n) - Number of periods
  - Result display with formatted currency
  - Active field highlighting
  - Blinking cursor indicator

KEYBOARD SHORTCUTS:
  - 0-9, .: Number input
  - Arrow Up/Left: Previous field
  - Arrow Down/Right: Next field
  - Tab: Cycle through fields
  - Enter/=: Calculate result
  - Escape/c: Clear active field
  - Backspace: Delete character

CALCULATION:
  - Formula: A = P(1 + r)^t
  - Where:
    * A = Final amount
    * P = Principal
    * r = Rate (as decimal)
    * t = Time periods
  - Currency formatting (K, M, B suffixes)


### VOICE INPUT SYSTEM
================================================================================

TECHNOLOGY:
  - Web Speech Recognition API
  - Browser compatibility: Chrome, Edge (webkit prefix)

IMPLEMENTATION:
  1. User clicks microphone button (🎤)
  2. SpeechRecognition instance created
  3. Language set to "en-US"
  4. Voice input captured
  5. Transcript parsed for commands

SUPPORTED VOICE COMMANDS:

Basic Calculator:
  - "power [base] to [exponent]"
    Example: "power 2 to 3" → 2^3

Scientific Calculator:
  - "sine of [angle]" → sin(angle)
  - "cosine of [angle]" → cos(angle)
  - "square root of [number]" → √(number)

Financial Calculator:
  - "principal [amount] dollars"
  - "rate [percentage]"
  - "time [years] years"
  - "calculate"


### WINDOW MANAGEMENT SYSTEM
================================================================================

DRAGGING:
  - Click and hold title bar
  - Move calculator anywhere on screen
  - Boundary constraints prevent off-screen movement
  - Uses mouse events (mousedown, mousemove, mouseup)

MINIMIZE/MAXIMIZE:
  - Click minimize button (−)
  - Calculator collapses to title bar only
  - Click maximize button (□) to restore
  - State managed with isMinimized boolean

CLOSE:
  - Click close button (✕)
  - Dispatches custom event: 'closeCalculator'
  - Event detail contains calculator type
  - Index.tsx listens for event and hides calculator

TRANSPARENCY:
  - Hover effect: opacity 0.7 → 1.0
  - Glassmorphism effect (backdrop-filter: blur)
  - Smooth transitions (0.3s ease)
